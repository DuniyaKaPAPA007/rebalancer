Kaam ka order

Isi kram mein — pehla step chhoda toh baaki nakli paise par chalega.
  1. Connect — Dhan credentials verify. Yahi tay karta hai ki capital kahan se aayega. Ek baar ka kaam.
  2. Watchlist — Trendlyne se nayi CSV drop karo.
  3. Plan — tumhare asli balance par plan banta hai. Koi order nahi jaata.
  4. Execute — pehle rehearsal, phir asli (haan type karna padta hai).
